# SIH26103 Model Limitations

1. The available project history is limited.
2. Early observations contain expected missing historical features.
3. Source-report quality can affect model inputs.
4. Reporting-format changes may require future feature-pipeline maintenance.
5. Predictions are estimates and contain uncertainty.
6. Model drift should be monitored after deployment.
7. Current model predicts physical progress, not a calibrated probability of delay.
8. Cost-overrun probability is not produced by this model.
9. Risk thresholds must be validated independently before production use.
